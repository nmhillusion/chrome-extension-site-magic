# Site Style Weaver — Chrome Web Store Listing

## Short description (132 chars max)

> Weave custom styles into any website — fonts, colors, spacing, corners and more, with live preview.

## Detailed description

Weave your own style into every corner of the web. Site Style Weaver lets you
restyle any website — change fonts, colors, spacing, rounded corners and text
emphasis — and see every tweak applied instantly.

### Features

* Multiple named style rules — style different parts of a page independently
* Click-to-pick element selector — point at any element to target it, or leave
  the target empty for a global style
* Rich styling controls — Google Fonts, font size, text and background colors,
  padding, border radius (px or %), bold / italic / underline toggles
* Live preview as you drag and type, with debounced saving
* Rules sync across your Chrome browsers via your Google account
* Copy-selector and one-click reset per rule

### How to use

1. Click the toolbar icon to open the Site Style Weaver side panel (pin it
   first for quick access).
2. Click "Add Rule", give it a name, then click the picker button and click any
   element on the page to target it — or leave the target empty to style the
   whole page.
3. Adjust fonts, colors, spacing and effects. Changes preview live and save
   automatically.
4. Reload any page and your styles re-apply themselves.

### Privacy

Everything stays with you. Rules are stored only in your browser's synced
storage. No accounts, no tracking, no analytics. (If you pick a Google Font,
your browser loads that font file from Google Fonts — that's the only network
request the extension ever triggers.)
